# LabQMS Frontend

This is a minimal React + Vite frontend for LabQMS browser-based data entry.

## Setup

1. Install dependencies:
   npm install

2. Start the dev server:
   npm run dev

3. Open the browser at the URL shown in the terminal.

## Functionality

- Create patients
- Create patient visits
- View created patients and visits
- Browse laboratory sections and tests

## Notes

Make sure the backend is running at `http://localhost:8000` before using the frontend.
